# skills — 제작 스킬 원문

AutoQC Studio는 프롬프트 작성과 검수에 제작 스킬을 적용합니다.

- **압축 규칙(compact)**: `server/skills.ts` 안에 들어 있는 짧은 규칙. 로컬·소형 LLM도 따라올 수 있게 빈칸(JSON 슬롯) 채우기 + 코드 점검으로 동작합니다.
- **원문 스킬(full)**: 이 폴더의 `.md` 파일을 시스템 프롬프트에 그대로 붙입니다. Claude처럼 긴 규칙을 소화하는 모델용입니다.

[모듈 · 설정] → "제작 스킬 적용"에서 고릅니다. 자동이면 Claude = 원문, 그 외 = 압축입니다.

| 파일 | 쓰이는 곳 |
|---|---|
| `seedance.md` | Seedance 계열 영상 프롬프트 |
| `leera.md` | 로케이션 이미지 프롬프트 (질문 없이 기본값으로 작성) |
| `shot-prep.md` | 검수: 3단계 검증 · 슬롭 검사 · 원인 진단 |
| `character-sheet.md` | 캐릭터 시트 작성·검수 |

파일이 없으면 압축 규칙만 씁니다. 개인 스킬 파일은 `.gitignore`로 저장소에서 제외됩니다.
